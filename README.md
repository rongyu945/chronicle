# 时序集 · ShixuJi

一个纯本地运行的 Android 生活管理应用：**待办 + 记账 + 模型看板**，风格参考 iOS 26 的「液态玻璃」。

- 包名：`com.rongyu.shixuji`
- 当前版本：**4.2.6**（versionCode 61）
- 技术栈：Kotlin + Jetpack Compose + Room（**原生**，非 WebView 套壳）
- 系统要求：Android 7.0（API 24）及以上
- APK 大小：约 15 MB（内含完整中文字体）
- 下载：[Releases 页面](https://github.com/rongyu945/chronicle/releases) —— APK 文件名 `shixuji-4.2.6.apk`
- **不申请任何权限、不联网**，所有数据只存在手机本地

---

## 一、这个 App 是做什么的

时序集合了四件事，都在同一个 App 里，底部四个入口：

| 入口 | 作用 |
| --- | --- |
| **待办** | 按年 / 月 / 周查看日历，管理每天要做的事 |
| **账目** | 记每天的花销和收入，看月度预算还剩多少 |
| **模型看板** | 集中查看各大模型 API 的额度与重置时间 |
| **设置** | 标签、预算、常用记账、模型 Key、外观、备份 |

## 二、功能一览

### 1. 待办

**三级日历钻取**：点标题在 年 → 月 → 周 之间切换。

- **年视图**：12 个月卡片（3 列），每张卡内嵌完整日期网格，日期按当天待办数量着色（热力图，越红越多），周末标红、今天红圈白字。
- **月视图**：单月完整日期网格，哪天有待办，那天日期下面有个小红点。
- **周视图**：上方一条「一 二 三 四 五 六 日」，下面就是当天的待办清单。

**翻页手势（分两块区域）**：

- 在**上面那条星期几**上左右滑 → **切换一周**
- 在**下面的待办列表**上左右滑 → **切换一天**

两个都是跟着手指走的动画，相邻的那周/那天会从旁边滑进来，松手决定翻过去还是弹回。

**一条待办**：项目名（必填）+ 备注（可选）+ 日期 + 优先级（4 档）。

- 点左边的勾选圈 = 完成 / 取消完成
- **长按卡片** → 取消 / 修改 / 删除
- **长按 ≡ 把手上下拖** → 手动调整这一天的顺序（手动顺序优先，新加的默认排最上）
- 删除后底部会弹出一条黑色提示，**5 秒内可点「撤销」**找回

**几类特殊分组**（在同一天的清单下方）：

- **每日固定**：按周循环的固定事项（如每周三交作业），每到那天自动出现；跨周自动清零重新计算
- **过往未完成**：今天之前还没做完的事，会一直挂在这儿提醒你，打勾会同步勾回它原本那一天
- **无期限**：没设日期的事，只在「今天」的列表里显示

**「今」按钮**：翻到别的日期时，右下角会浮出一个白底的「今」，点一下立刻回到今天。

### 2. 账目

- 上方是**汇总卡**：本月支出大字 + 今日 / 本周 / 收入 + **月度预算进度条**（超出预算会变黄并标出超支多少）。**翻到别的月份，卡片上的数字和「本月」字样都会跟着变**。
- 中间是**星期条**（和待办同款），可点选日期；在条上滑 = 换周，在下面列表上滑 = 换天。
- 下面是**当天的账目**，按标签分组排列，每条前面有一个该标签颜色的小圆点。
- **常用记账**：把常记的几笔存成快捷按钮，点一下直接记当天一笔。
- **记一笔**：金额 → 收支 → 备注 → 标签（打开就弹出数字键盘）。
- **长按一条账目** → 取消 / 修改 / 删除（修改会预填原来的金额、备注、标签）。

### 3. 模型看板

- 按模型名分组，显示额度、重置周期、重置日期。
- 同一个模型下的多个 Key 会合并成一组，点 ⌃ 展开/收起。
- 点 ⓘ 看额度详情：Base URL、API Key、开放平台。**API Key 默认打码**（只露头 4 位和尾 4 位），要看全需手动点「显示 Key」。
- 数据全部在「设置 → 模型管理」里自己录入，App 不联网也不预置任何内容。

### 4. 设置

- **待办**：循环待办管理、导出未完成待办
- **账单**：标签管理（12 种颜色，可增删改）、月度预算、常用记账、账单总览
- **大模型列表**：模型管理（添加模型 / 添加 Key）
- **界面显示设置**：
  - 使用宋体（开关）
  - 外观模式：跟随系统 / 浅色 / 深色
  - 字号：小 / 标准 / 大（0.9 / 1.0 / 1.15 倍）
  - 底栏排序：调整四个入口的顺序，排第一的那个就是打开 App 的默认页
- **数据**：备份 / 恢复（导出一个 JSON 文件，换机时导回去即可）
- **关于**：版本号、作者

## 三、界面与动效

- **液态玻璃**：柔光色斑背景 + 半透明玻璃卡片 + 一道高光描边；打开弹窗时背后的主界面会实时模糊（Android 12 及以上），玻璃弹窗盖在模糊层上。
- **浮动胶囊底栏**：四个自绘图标（同一套 24 网格、2dp 描边），选中态是一枚**浅红色圆**，把图标和文字一起包住，切换时圆会滑过去。图标与文字间距 1.5dp。
- **全局宋体**：App 内置了一份 Songti SC，中文宋体、西文衬线。数字和西文字母的高度做过专门校准，与中文等高（默认比中文矮 29%，已拉伸对齐后再收 5%）。
- **标题跟随滚动**：往上滑，页面大标题会从 28sp 缩到 17sp（设置二级页 20sp → 14sp），并浮出标题条。
- **按下去有反馈**：全 App 关掉了安卓的灰色涟漪（不好看），改成**按压缩放**——点悬浮按钮、点卡片都会轻微缩一下再弹回。
- **早晚启动页**：只在 0:00–7:00 和 21:00–24:00 出现，配一句《红楼梦》的诗句（诗池 82 句、16 位作者，每次随机抽一句；早上浅色、晚上深色）。其余时间打开直接进主界面。

## 四、数据与隐私

- 所有内容都存在手机本地的 SQLite 数据库里（Room）。
- **App 的清单里没有申请任何权限**（连联网权限都没有），它无法联网，也不会上传任何东西。
- 备份功能导出的 JSON 文件由你自己选择保存位置，文件里包含你的待办、账目、标签和模型 Key。
- ⚠️ 模型看板里填的 API Key 是**明文存在本地数据库**里的，没有额外加密（只是显示时打了码）。请勿在共用设备上录入敏感 Key。

## 五、安装

1. 从 [Releases](https://github.com/rongyu945/chronicle/releases) 下载 `shixuji-4.2.6.apk`，传到手机（微信/数据线/网盘都行）。
2. 点击安装，若提示「不允许安装未知来源应用」，在系统设置里允许一次即可。
3. 签名信息：`CN=RongYu`。同一个签名的后续版本可以直接覆盖安装，**数据不会丢**。

## 六、开发者信息（构建）

源码工程不含签名文件（`release.keystore` 与 `keystore.properties` 出于安全考虑不随源码分发），本地构建流程如下：

```bash
# 仓库自带 gradle wrapper，直接：
./gradlew assembleRelease        # 产物：app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # 单元测试（13 项，金额换算 + 日期）

# 若不用 wrapper（本机是 JDK 21 + Gradle 8.14）：
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"
gradle assembleRelease
```

- **工具链**：JDK 21 · Gradle 8.14 · AGP 8.x · compileSdk 34 · minSdk 24 · targetSdk 34
- **依赖**：Compose BOM 2024.12.01、Material 3、Room 2.6.1（KSP）、Lifecycle ViewModel Compose
- **结构**：单 Activity + Compose 状态导航（不用 Navigation 组件，层级切换用 `BackHandler` 接管返回键）
  - `MainScreen.kt` 主框架 / 底栏 / 切页动画
  - `ui/TodoScreen.kt` 待办（年/月/周）
  - `ui/AccountScreen.kt` 账目
  - `ui/ModelBoardScreen.kt` 模型看板
  - `ui/SettingsScreen.kt` 设置（含九个二级页）
  - `ui/Glass.kt` 玻璃质感组件库（卡片/弹窗/左滑行/撤销条/按压反馈）
  - `ui/PeriodSwipe.kt` 跟手翻页容器
  - `data/AppDatabase.kt` Room 实体与 DAO
  - `res/font/songti_sc.ttf` 内置字体（做过西文等高处理）

## 七、已知限制

- 没有云同步 / 多设备同步，数据只在本机，换机请用「备份 / 恢复」。
- 液态玻璃是**近似的**——Android 系统没有 iOS 那样的背景折射能力，靠「半透明 + 高光描边 + 主界面模糊」逼近，达不到 iOS 26 的折射变形效果。
- 月度预算只做整月总额，不做分类预算。
- 不做农历、节假日/调休标注。
- 日历范围限定在 **2008 – 2100** 年。
- 卡片左滑快捷操作（露出「完成 / 删除」按钮）在周视图里让位给了「列表横滑换天」，需要删除或修改请**长按卡片**，完成请**点勾选圈**。
