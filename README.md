# 时序集 · ShixuJi

一个纯本地运行的 Android 生活管理应用：**待办 + 记账**，柔光色斑背景 + 白色玻璃卡片，深浅双模式。

- 包名：`com.rongyu.shixuji`
- 当前版本：**5.2.3**（versionCode 528）
- 技术栈：Kotlin + Jetpack Compose + Room（**原生**，非 WebView 套壳）
- 系统要求：Android 7.0（API 24）及以上
- APK 大小：约 15 MB（内含完整中文字体）
- 下载：[Releases 页面](https://github.com/rongyu945/chronicle/releases) —— APK 文件名 `shixuji-5.2.3.apk`
- **不申请任何权限、不联网**，所有数据只存在手机本地

---

## 一、这个 App 是做什么的

时序集目前做两件事，在同一个 App 里，底部三个入口：

| 入口 | 作用 |
| --- | --- |
| **待办** | 按年 / 月 / 周查看日历，管理每天要做的事 |
| **账目** | 记每天的花销和收入，看月度预算还剩多少 |
| **设置** | 标签、预算、常用记账、外观、备份 |

> 说明：4.x 时代的「模型看板」（大模型 API 额度记录）已在 **5.1.0 整体移除**（含设置页入口、数据表与备份字段）。
> 老用户升级时会自动删掉这张表，待办与账目数据原样保留。

## 二、功能一览

### 1. 待办

**三级日历钻取**：点标题在 年 → 月 → 周 之间切换。

- **年视图**：12 个月卡片（3 列），每张卡内嵌完整日期网格，日期按当天待办数量着色（热力图，越红越多），周末标红、今天红圈白字。
- **月视图**：单月完整日期网格，哪天有待办，那天日期下面有个小红点。
- **周视图**：上方一条「一 二 三 四 五 六 日」，下面就是当天的待办清单。

**翻页手势（分两块区域）**：

- 在**上面那条星期几**上左右滑 → **切换一周**
- 在**下面的待办列表**上左右滑 → **切换一天**（按天缓存列表状态，切过去先显示旧内容再落位，滑动不卡顿）

两个都是跟着手指走的动画，相邻的那周/那天会从旁边滑进来，松手决定翻过去还是弹回。

**一条待办**：项目名（必填）+ 备注（可选）+ 日期 + 优先级（4 档）。

- 点左边的勾选方框 = 完成 / 取消完成（点文字是打开详情，只有点方框才勾选）
- **长按卡片** → 取消 / 修改 / 删除（修改会预填原来的内容）
- **长按 ≡ 把手上下拖** → 手动调整这一天的顺序（手动顺序优先，新加的默认排最上）
- 删除后底部会弹出一条黑色提示，**5 秒内可点「撤销」**找回
- **勾选完成时列表原地不动**（5.2.3 起）：只有当天真的多出新条目 / 有事项改期进来才回到顶部，勾掉、删掉、取消完成都不会把列表拽回顶上；被移除的行会淡出 240ms 再腾位
- **改了日期自动排到那天最前**（5.2.2 起）：详情页把日期改到另一天，这条会重新落到那天列表的最上面（同一天只改标题不会重排）

**几类特殊分组**（在同一天的清单下方）：

- **每日固定**：按周循环的固定事项（如每周三交作业），每到那天自动出现；跨周自动清零重新计算
- **过往未完成**：今天之前还没做完的事，会一直挂在这儿提醒你，打勾会同步勾回它原本那一天
- **无期限**：没设日期的事，只在「今天」的列表里显示

**「今」按钮**：翻到别的日期时，右下角会浮出一枚磨砂玻璃的「今」，点一下立刻回到今天（右上角那枚是玻璃「＋」）。

### 2. 账目

- 上方是**汇总卡**：本月支出大字 + 今日 / 本周 / 收入 + **月度预算进度条**（超出预算会变黄并标出超支多少）。**翻到别的月份，卡片上的数字和「本月」字样都会跟着变**。
- 中间是**星期条**（和待办同款），可点选日期；在条上滑 = 换周，在下面列表上滑 = 换天。
- 下面是**当天的账目**，按标签分组排列，每条前面有一个该标签颜色的小圆点。
- **常用记账**：把常记的几笔存成快捷按钮，点一下直接记当天一笔。
- **记一笔**：金额 → 收支 → 备注 → 标签（打开就弹出数字键盘）。
- **长按一条账目** → 取消 / 修改 / 删除（修改会预填原来的金额、备注、标签）。
- 新记一笔 / 改完之后**列表自动回到顶部**，不用自己往上推。
- **新增 / 修改弹窗改成紧凑版**（5.1.3 起）：弹窗比旧版矮 30% 左右、宽度自适应小屏，内容多时可滚动；金额填错时错误提示单独占一行完整显示，不会再被输入框高度裁掉下半截（5.1.7 修）。

### 3. 设置

- **待办**：循环待办管理、导出未完成待办
- **账单**：标签管理（**24 种颜色**，按 红 / 橙黄 / 绿 / 青蓝 / 紫粉 / 中性 六系分组，可增删改）、月度预算、常用记账、账单总览、支出明细
- **界面显示设置**：
  - 使用宋体（开关）
  - 外观模式：跟随系统 / 浅色 / 深色
  - 字号：小 / 标准 / 大（0.9 / 1.0 / 1.15 倍）
  - 底栏排序：调整三个入口的顺序，排第一的那个就是打开 App 的默认页
- **数据**：备份 / 恢复（导出一个 JSON 文件，换机时导回去即可）。5.2.0 起恢复改为**先整份纯函数校验、再单事务落库**：文件格式不对（-1）、来自更新版本（-2）、内容损坏（-3）会整份拒绝，绝不留半套数据；缺段的表保持原样，界面设置整组以备份为准
- **关于**：版本号、作者

## 三、界面与动效

- **玻璃卡片**：柔光色斑背景（亮暗双模式、强度统一 0.42）+ 半透明卡（亮色纯白 85%、深色暖灰），卡片下有柔和层压住背景细节；**高光边框**为一条顶光 + 整圈淡描边（亮色浅紫、深色白，账目 / 待办 / 底栏 / 弹窗统一）。
- **背景模糊弹窗**：打开弹窗时背后的主界面会实时模糊（Android 12 及以上），半透明弹窗盖在模糊层上。
- **浮动胶囊底栏**：三个自绘图标（同一套 24 网格、2dp 描边），选中态是一枚**浅红色圆**，把图标和文字一起包住，切换时圆会滑过去。尺寸由单一系数 `TAB_BAR_SCALE = 0.90` 派生（每项 75.6dp、图标 21.6dp、文字 9.9sp，整体居中），改一处全栏等比缩放；5.1.1 起选择框描边统一为主题红 42%（深色 55%），不再几乎看不见。
- **全局宋体**：App 内置了一份 Songti SC，中文宋体、西文衬线。数字和西文字母的高度做过专门校准，与中文等高（默认比中文矮 29%，已拉伸对齐后再收 5%）。
- **标题跟随滚动**：往上滑，页面大标题会从 28sp 缩到 17sp（设置二级页 20sp → 14sp），并浮出标题条。
- **按下去有反馈**：全 App 关掉了安卓的灰色涟漪（不好看），改成**按压缩放**——点悬浮按钮、点卡片都会轻微缩一下再弹回。
- **跨周与切天只有一条运动线**（5.1.6 起）：周条、那枚红点和日列表由同一个 `offsetFraction` 驱动，跨周拖动时周条在第一帧就跟着手指走，不再「列表滑完再补滑」；红点整条只画一枚。表头 ‹ › 与「今」按钮也从硬切改成朝目标方向滑动 0.28s（5.1.2 起）。
- **早晚启动页**：只在 0:00–7:00 和 21:00–24:00 出现，配一句《红楼梦》的诗句（诗池 **119 句 / 23 位作者 / 17 个回目段**，每次随机抽一句；早上浅色、晚上深色）。正文整句不换行、字号从 18sp 自适应缩到 10sp（系统字号放大 1.15 档仍装得下）。其余时间打开直接进主界面。

## 四、数据与隐私

- 所有内容都存在手机本地的 SQLite 数据库里（Room）。
- **App 的清单里没有申请任何权限**（连联网权限都没有），它无法联网，也不会上传任何东西。
- 备份功能导出的 JSON 文件由你自己选择保存位置，文件里包含你的待办、账目和标签。
  （5.1.0 删掉模型看板后，备份文件里**不再有任何 API Key 字段**，可以放心留存。）
- 新增 / 记账改用 `@Insert` 返回的真实 rowId（5.2.0 起不再预分配 `MAX(id)+1`），撤回与并发写入不会撞 id；循环待办的跨周重置与周戳写入放进同一个数据库事务。

## 六、开发者信息（构建）

源码工程不含签名文件（`release.keystore` 与 `keystore.properties` 出于安全考虑不随源码分发），本地构建流程如下：

```bash
# 仓库自带 gradle wrapper，直接：
./gradlew assembleRelease        # 产物：app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # 单元测试（36 项：金额换算 + 日期 + 备份编解码 16 项 + 底栏顺序）

# 若不用 wrapper（本机是 JDK 21 + Gradle 8.14）：
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"
gradle assembleRelease
```

- **工具链**：JDK 21 · Gradle 8.14 · AGP 8.x · compileSdk 34 · minSdk 24 · targetSdk 34
- **依赖**：Compose BOM 2024.12.01、Material 3、Room 2.6.1（KSP）、Lifecycle ViewModel Compose
- **结构**：单 Activity + Compose 状态导航（不用 Navigation 组件，层级切换用 `BackHandler` 接管返回键）
  - `MainScreen.kt` 主框架 / 底栏 / 切页动画
  - `ui/TodoScreen.kt` 待办（年/月/周）
  - `ui/AccountScreen.kt` 账目
  - `ui/SettingsScreen.kt` 设置（含九个二级页）
  - `ui/Glass.kt` · `ui/LiquidGlass.kt` · `ui/GlassFab.kt` 玻璃质感组件库（卡片 / 弹窗 / 左滑行 / 撤销条 / 玻璃圆钮 / 按压反馈）
  - `ui/BottomTabBar.kt` 浮动胶囊底栏（`TAB_BAR_SCALE` 统一派生尺寸）
  - `ui/motion/WeekMotionMath.kt` · `ui/motion/UnifiedWeekDayNavigator.kt` 周条 / 红点 / 日列表的统一运动源（含「减少动态效果」）
  - `ui/ShixuDialog.kt` 紧凑弹窗外壳 · `ui/Chips.kt` 芯片（支持 compact）
  - `data/BackupCodec.kt` 备份的纯函数编解码与校验（`ERR_FORMAT -1` / `ERR_NEWER -2` / `ERR_CORRUPT -3` / 写库失败 -4）
  - `ui/PeriodSwipe.kt` 跟手翻页容器 · `ui/SwipeRow.kt` 左滑行 · `ui/CursorEnd.kt` 光标定位
  - `ui/CalendarGrids.kt` 年 / 月 / 周日历网格 · `ui/AccountRow.kt` 账目行
  - `data/AppDatabase.kt` Room 实体与 DAO（当前 schema 版本 6；schema 3–6 的 JSON 都在 `app/schemas/`）· `AppContainer.kt` 依赖装配与迁移
  - `res/values-night/` 启动主题（深色冷启动不再闪白底）
  - `res/font/songti_sc.ttf` 内置字体（做过西文等高处理）

## 七、已知限制

- 没有云同步 / 多设备同步，数据只在本机，换机请用「备份 / 恢复」。
- 卡片玻璃是**近似的**——Android 系统没有 iOS 那样的背景折射能力，靠「柔光背景 + 半透明卡片 + 主界面模糊」逼近，达不到 iOS 26 的折射变形效果。
- 月度预算只做整月总额，不做分类预算。
- 不做农历、节假日/调休标注。
- 日历范围限定在 **2008 – 2100** 年。
- 卡片左滑快捷操作（露出「完成 / 删除」按钮）在周视图里让位给了「列表横滑换天」，需要删除或修改请**长按卡片**，完成请**点勾选方框**。
