# 时序集 · ShixuJi

一个纯本地运行的 Android 生活管理应用：**待办 + 记账**，风格参考 iOS 26 的「液态玻璃」。

- 包名：`com.rongyu.shixuji`
- 当前版本：**5.5.1**（versionCode 537）
- 本版改动：**循环待办右侧的图标改成自己画的「闭环双箭头」**（原来是 emoji 🔁）；上一版的循环待办改版（开始日期 + 下一次提醒日期推间隔）与 ＋ / 今 放大也在这个系列里
- 技术栈：Kotlin + Jetpack Compose + Room（**原生**，非 WebView 套壳）
- 系统要求：Android 7.0（API 24）及以上
- APK 大小：约 14.4 MB（内含完整中文字体）
- **不申请任何权限、不联网**，所有数据只存在手机本地

---

## 一、这个 App 是做什么的

时序集把「一天怎么过、钱花在哪」放在同一个 App 里，底部三个入口：

| 入口 | 作用 |
| --- | --- |
| **待办** | 按年 / 月 / 周查看日历，管理每天要做的事 |
| **账目** | 记每天的花销和收入，看月度预算还剩多少 |
| **设置** | 标签、预算、常用记账、总览、外观、备份与自动备份 |

配色取自《中国风传统色卡》：底色宣纸 `#FBF6ED`、主题红妃色 `#ED5736`、收入绿松花绿 `#057748`、正文乌黑 `#392F41`。

## 二、功能一览

### 1. 待办

**三级日历钻取**：点标题在 年 → 月 → 周 之间切换。

- **年视图**：12 个月卡片（3 列），每张卡内嵌完整日期网格，日期按当天待办数量着色（热力图，越红越多），周末标红、今天红圈白字。
- **月视图**：单月完整日期网格，哪天有待办，那天日期下面有个小红点。
- **周视图**：上方一条「一 二 三 四 五 六 日」，下面就是当天的待办清单。

**翻页手势（分两块区域）**：

- 在**上面那条星期几**上左右滑 → **切换一周**
- 在**下面的待办列表**上左右滑 → **切换一天**

两个都是跟着手指走的动画，相邻的那周/那天会从旁边滑进来，松手决定翻过去还是弹回。

**一条待办**：项目名（必填）+ 备注（可选）+ 日期 + 优先级（4 档）。

- 点左边的勾选圈 = 完成 / 取消完成
- **长按卡片** → 取消 / 修改 / 删除
- **长按 ≡ 把手上下拖** → 手动调整这一天的顺序（手动顺序优先，新加的默认排最上）
- 删除 / 取消完成后底部弹一条灰底提示，**5 秒内可点「撤回」**找回
- 勾掉一条不会把列表跳回顶部（只有「当天条目变多」才回顶）

**几类特殊分组**（在同一天的清单下方）：

- **已完成**：当天到期已完成 ∪ 今天完成的，勾错能立刻撤回
- **循环待办**：按间隔提醒的事（例如每 4 天浇一次水），到日子自动出现；**设置成「开始日期 + 下一次提醒日期」，间隔天数由这两个日期算出来**；勾选按天记，昨天的勾不会串到今天
- **过往未完成**：今天之前还没做完的事，会一直挂在这儿提醒你，打勾会同步勾回它原本那一天
- **无期限**：没设日期的事，只在「今天」的列表里显示

**「今」按钮**：翻到别的日期时，右下角会浮出一个白底的「今」，点一下立刻回到今天。

### 2. 账目

- 上方是**汇总卡**：本月支出大字 + 今日 / 本周 / 收入 + **月度预算进度条**（超出预算会变黄并标出超支多少）。翻到别的月份，卡片上的数字和「本月」字样都会跟着变。
- 中间是**星期条**（和待办同款），可点选日期；在条上滑 = 换周，在下面列表上滑 = 换天。
- 下面是**当天的账目**，按标签分组排列，每条前面有一个该标签颜色的小圆点。没有标签的账目单独归到「未分类」，固定垫在最下面。
- **记一笔**：金额 → 收支 → 备注 → 标签（打开就弹出数字键盘）。标签按**最近 30 天用得多少**排序，常用的在最前面。
- **长按一条账目**（或点开）→ 修改 / 删除，删除后 5 秒内可撤回。
- **常用记账**：把常记的几笔存成快捷按钮，点一下直接记当天一笔。

### 3. 设置

- **待办**：循环待办管理、导出未完成待办（复制成文本）
- **账单**：标签管理、月度预算、常用记账、账单总览（按月查看）
- **标签管理**：24 色色板（取自传统色：朱／黄绿／青蓝紫墨三行），可增删改。**已被其它标签占用的颜色不再显示**，避免撞色。
- **支出明细**：当月标签占比饼图。**饼图下面每一条都能点开**，弹窗列出这个标签这个月的每一笔（备注、时间、金额）与合计。
- **界面显示设置**：宋体开关、外观模式（跟随系统 / 浅色 / 深色）、字号（小 / 标准 / 大）、底栏排序（排第一的入口就是打开 App 的默认页）
- **数据**：备份 / 恢复、**自动备份**
- **关于作者**：作者、版本号

## 三、自动备份（5.3.0 新增）

**为什么有它**：数据原本只存在 App 私有目录，一旦 App 被卸载 / 清数据，全部归零。现在只要改过任何一条，App 会自动把整份数据写到 App 之外。

- **触发**：新增、修改、删除、勾选完成、取消完成、恢复备份、拖动排序——任何一次落库，都在 1.5 秒内更新备份（连续操作只写一次）。App 启动时也会先打一份底。
- **落在哪**：
  - `下载 / 时序集备份 / 时序集_自动备份.json` —— 最新的一份，每次改动覆盖更新
  - `下载 / 时序集备份 / 时序集_自动备份_YYYY-MM-DD.json` —— 每天一份快照，最多保留 10 天
- **卸载、重装、清数据之后这两个文件依然在**（走系统 MediaStore，API 29+ 不需要任何权限）。
- **怎么找回**：`设置 → 备份 / 恢复 → 从备份文件恢复`，在系统文件选择器里进「下载 / 时序集备份」选它，确认预览里的条数无误再点「恢复」。
- **空库不会覆盖真备份**：重装后库里是空的，此时不会拿空备份去覆盖旧的那份（这一点单独做了保护，也实测过）。
- 可以随时在 `设置 → 数据 → 自动备份` 里关掉它、看上次备份时间，或点「立即备份一次」。
- 备份文件是**明文 JSON**，含金额，分享出去前想清楚。

## 四、界面与动效

- **液态玻璃**：宣纸底 + 传统淡色柔光色斑（粉红／淡青／姜黄／青白）+ 半透明玻璃卡片 + 一道高光描边；打开弹窗时背后的主界面会实时模糊（Android 12 及以上），玻璃弹窗盖在模糊层上。深色模式是暖深底（`#2E2A26`）。
- **浮动胶囊底栏**：三个自绘图标（同一套 24 网格、2dp 描边），选中态是一枚**浅红色圆**，把图标和文字一起包住，切换时圆会滑过去。
- **全局宋体**：App 内置一份 Songti SC，中文宋体、西文衬线。数字和西文字母的高度做过校准，与中文等高。
- **标题跟随滚动**：往上滑，页面大标题会从 28sp 缩到 17sp（设置二级页 20sp → 14sp），并浮出标题条。
- **按下去有反馈**：关掉安卓的灰色涟漪，改成**按压缩放**——点悬浮按钮、点卡片都会轻微缩一下再弹回。
- **早晚启动页**：只在 0:00–7:00 和 21:00–24:00 出现，配一句《红楼梦》的诗句（早上浅色、晚上深色），正文用内置的 119 句诗词库随机。其余时间打开直接进主界面。

## 五、数据与隐私

- 所有内容都存在手机本地的 SQLite 数据库里（Room）。
- **App 的清单里没有申请任何权限**（连联网权限都没有），它无法联网，也不会上传任何东西。
- 手动备份导出的 JSON 由你自己选保存位置；自动备份写在系统「下载 / 时序集备份」。
- 备份文件都是**明文**，含账目金额，请自行保管。

## 六、安装

1. 把 `时序集5.5.1.apk` 传到手机（微信/数据线/网盘都行）。
2. 点击安装，若提示「不允许安装未知来源应用」，在系统设置里允许一次即可。
3. 签名信息：`CN=RongYu`。同一个签名的后续版本可以直接覆盖安装，**数据不会丢**（数据库版本 6 → 7 会自动迁移）。

## 七、开发者信息（构建）

源码工程不含签名文件（`release.keystore` 与 `keystore.properties` 出于安全考虑不随源码分发），本地构建流程：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export PATH="/opt/homebrew/opt/gradle@8/bin:$JAVA_HOME/bin:$PATH"

cd ShixuJiNative
gradle assembleRelease        # 产物：app/build/outputs/apk/release/app-release.apk
gradle testDebugUnitTest      # 单元测试 49 个
gradle lintDebug              # 0 error
export ANDROID_SERIAL=emulator-5554
gradle connectedDebugAndroidTest   # 仪器测试 7 个；**必须限定设备**，否则 ddmlib 会遍历所有在线设备
```

- **工具链**：JDK 21 · Gradle 8.14 · AGP 8.x · compileSdk 34 · minSdk 24 · targetSdk 34
- **依赖**：Compose BOM 2024.12.01、Material 3、Room 2.6.1（KSP）、Lifecycle ViewModel Compose
- **结构**：单 Activity + Compose 状态导航（不用 Navigation 组件，层级切换用 `BackHandler` 接管返回键）
  - `MainScreen.kt` 主框架 / 底栏 / 切页动画
  - `ui/TodoScreen.kt` 待办（年/月/周）
  - `ui/AccountScreen.kt` 账目
  - `ui/SettingsScreen.kt` 设置（含各二级页）
  - `ui/Glass.kt` 玻璃质感组件库（卡片/弹窗/撤销条/按压反馈）
  - `ui/PeriodSwipe.kt` 跟手翻页容器
  - `data/AppDatabase.kt` Room 实体、DAO、版本与迁移
  - `data/BackupCodec.kt` 备份 JSON 的解析与校验（纯函数，落库前整份校验）
  - `data/BackupWriter.kt` 备份 JSON 的唯一生产者（导出与自动备份共用）
  - `data/AutoBackup.kt` 自动备份（Room 失效追踪触发 + MediaStore 写入）
  - `data/TagPalette.kt` 24 色色板
  - `res/font/songti_sc.ttf` 内置字体（做过西文等高处理）
- **测试**：`app/src/test`（JVM 单测 49）+ `app/src/androidTest`（迁移与 DAO 冒烟 7）

## 八、已知限制

- 没有云同步 / 多设备同步，换机请用「备份 / 恢复」。
- 自动备份依赖系统 MediaStore：**Android 10（API 29）及以上**才写到「下载」目录；Android 7–9 只写 App 私有目录（卸载即丢），这类机器请定期手动导出一次备份。
- 液态玻璃是**近似的**——Android 系统没有 iOS 那样的背景折射能力，靠「半透明 + 高光描边 + 主界面模糊」逼近。
- 月度预算只做整月总额，不做分类预算。
- 不做农历、节假日/调休标注。
- 日历范围限定在 **2008 – 2100** 年。
- 卡片左滑快捷操作在周视图里让位给了「列表横滑换天」，需要删除或修改请**长按卡片**，完成请**点勾选圈**。
